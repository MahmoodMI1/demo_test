# System Quest Log

A Solo Leveling–inspired todo app. Tasks are quests: give each one a rank (E–S), clear it to earn XP, and level up your Hunter from E-Rank to S-Rank.

## Features

- Status window with Level, Hunter Rank, Title and an XP bar
- Quests ranked E–S with matching XP rewards (10–300 XP)
- "System" notifications for cleared quests and level-ups
- Active / Cleared tabs
- Progress saved in the browser (`localStorage`)

## Getting started

```bash
npm install
npm run dev
```

Built with React + Vite.
